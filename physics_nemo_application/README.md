# PhysicsNeMo Application examples

Examples for the [PhysicsNeMoApplication](https://github.com/KratosMultiphysics/Kratos/tree/master/applications/PhysicsNeMoApplication), the bridge between Kratos Multiphysics and [NVIDIA PhysicsNeMo](https://developer.nvidia.com/physicsnemo): training ML surrogates on real Kratos solves, deploying them inside the solution loop with governance (model cards, out-of-distribution guards, uncertainty), and differentiating through the real FEM assembly.

All examples are **self-contained and CPU-capable** (a GPU accelerates training but is not required; everything here runs on an 8 GB consumer GPU or without one). Every figure in the `data/` folders is generated by the scripts — re-running them regenerates the documentation. Common requirements: `nvidia-physicsnemo`, `torch`, `matplotlib`; per-case extras are listed in each README.

## Use cases

| Example | What it demonstrates |
|---|---|
| [Thermal surrogate lifecycle](use_cases/thermal_surrogate_lifecycle/README.md) | The complete workflow: dataset from real solves → FNO ensemble with model cards + OOD guard → governed in-loop deployment with uncertainty → validation against the solver → ONNX distillation + Triton serving layout |
| [Transient thermo-mechanical surrogate](use_cases/transient_thermomechanical_surrogate/README.md) | Coupled thermal–structural cooling (contraction) as ground truth; autoregressive surrogates, single-step vs BPTT training, animated rollout on an unseen cooling schedule |
| [GNN + exact shape optimization](use_cases/gnn_and_exact_shape_optimization/README.md) | MeshGraphNet on the solver's own mesh graph; exact adjoint shape gradients through the real FEM assembly, verified against re-solved finite differences, driving an FFD shape optimization (includes a notebook) |
| [Superresolution + diffusion](use_cases/superresolution_and_diffusion/README.md) | SRResNet resolution transfer between model parts; CorrDiff two-stage diffusion downscaling of genuinely under-resolved solves, with calibrated ensemble uncertainty |
| [Transient in-loop superresolution](use_cases/transient_superresolution/README.md) | SuperResolutionProcess attached to a *running* transient analysis, upscaling every step; a TorchScript bilinear+correction upsampler halves the interpolation error |
| [Physics-refined superresolution](use_cases/physics_informed_superresolution/README.md) | 3D coarse-vs-fine solves; the differentiable PDE residual grades the upsampler's output and refines it below the fine solve's own residual |
| [Lid-driven cavity GNN](use_cases/fluid_cavity_gnn/README.md) | First fluid case: Navier–Stokes cavity solves (VMS), a MeshGraphNet propagating boundary conditions through the mesh graph to the recirculating flow |
| [PINN forward + inverse](use_cases/pinn_forward_and_inverse/README.md) | Mesh-free PinnSolveProcess vs the FEM solution, and inverse conductivity recovery from field observations |
| [Surrogate-driven remeshing](use_cases/surrogate_driven_remeshing/README.md) | The residual-scoring → MMG loop: refine exactly where the surrogate's physics error lives, no reference solution needed |
| [Lagrangian particle surrogate](use_cases/lagrangian_particle_surrogate/README.md) | Meshless: a learned acceleration integrated into particle positions by ParticleInferenceProcess, de-normalized by the model card |
| [Animated adaptive remeshing](use_cases/animated_adaptive_remeshing/README.md) | The mesh chases a moving source: surrogate-residual MMG adaptation per cycle, recorded by core Kratos' new TransientPlotter (topology changes every frame) |
| [Active learning](use_cases/active_learning/README.md) | Kratos as the labeler inside physicsnemo's active-learning loop — with the honest result that smooth families saturate early, and where the disagreement budget actually goes |
| [Co-simulation surrogate](use_cases/cosim_surrogate/README.md) | A trained checkpoint as a first-class CoSimulation solver: Aitken-accelerated strong coupling landing on the learned operator's fixed point to 1e-14 |
| [Uncertainty and trust](use_cases/uncertainty_and_trust/README.md) | Ensemble spread vs actual error, calibration metrics catching over-confident error bars, and the OOD guard — three composing views of surrogate trust |
| [Hybrid initialization](use_cases/hybrid_initialization/README.md) | The surrogate accelerating the solver itself: warm-starting Newton–Raphson on a geometrically nonlinear cantilever, 25 % of the iterations saved — plus the measured lesson that Newton rewards *smooth* seeds |
| [Implicit geometry + SDF surrogate](use_cases/implicit_geometry_sdf_surrogate/README.md) | Meshes generated straight from signed distance functions, solved, and learned through a ladder of autograd-computed SDF encodings (value → gradient → curvature) that generalizes across shapes |
| [Sparse-sensor field inversion](use_cases/sparse_sensor_inversion/README.md) | What ten sensors tell you about the whole field: a mask-conditioned diffusion model reconstructs full temperature fields, ensemble std as inversion uncertainty |
| [ROM-space temporal surrogate](use_cases/rom_temporal_surrogate/README.md) | RomApplication writes the POD basis, physicsnemo's temporal attention learns the dynamics in 8 coefficients, and an unseen conductivity rolls out to a 2 % full-space field |

## Running

```bash
export PYTHONPATH=/path/to/Kratos/bin/Release
export LD_LIBRARY_PATH=/path/to/Kratos/bin/Release/libs:$LD_LIBRARY_PATH
cd <example>/source
python3 01_....py   # scripts are numbered and run in order
```

Required Kratos applications: `ConvectionDiffusionApplication`, `LinearSolversApplication` (all cases); `StructuralMechanicsApplication` + `ConstitutiveLawsApplication` (transient thermo-mechanical case); `StructuralMechanicsApplication` (hybrid initialization); `RomApplication` (ROM-space temporal surrogate); `MeshingApplication` with MMG (remeshing cases); `CoSimulationApplication` + `MappingApplication` (co-simulation case).
